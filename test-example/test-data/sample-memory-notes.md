# Sample Memory Notes

## Project Context
- This is a test project for rovo-code-flow CLI
- Testing all available commands and parameters
- Verifying functionality across different categories

## Development Notes
- Using Node.js and TypeScript
- CLI built with Commander.js
- Testing framework uses custom test runner

## Agent Capabilities
- SPARC agents: architect, coder, tdd, security, devops
- Event Modeling agents: modeler, timeline, ui, state, mapper
- Swarm coordination with parallel and sequential execution

## Integration Points
- ACLI integration for Atlassian services
- MCP server management
- Memory file system for knowledge retention
- Session management for conversation history

- Core commands: init, start, interactive
- Agent commands: sparc, event, agent, swarm
- System commands: status, memory, mcp
- Tool commands: acli
